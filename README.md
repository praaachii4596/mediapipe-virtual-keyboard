# 🎹 Virtual Keyboard with Hand Tracking 🤚🖥️

A virtual keyboard powered by **Mediapipe** hand tracking and **OpenCV** computer vision!  
Type in your favorite apps using natural hand gestures in front of your webcam 🖐️✨.

---

## 🚀 Features

- 🖐️ Real-time hand and finger tracking with Mediapipe.
- 👆 Detect pinch gestures to simulate key presses.
- 🎨 Transparent, stylish keyboard overlay with visual feedback.
- 🔠 Shift key support for uppercase letters.
- ⌫ Backspace and ␣ Spacebar keys included.
- 🪟 Always-on-top click-through window that doesn’t block other apps.
- ✋ Drag and move the keyboard anywhere on screen.
- ⏳ Input debouncing to avoid repeat accidental typing.

---

## 🛠️ Setup and Requirements

Needs Python 3.9+ and the following dependencies:

- `opencv-python`
- `mediapipe`
- `pillow`
- `pynput`

---

### 📦 Install Dependencies

Run this command in your terminal or command prompt:

```commandline
pip install opencv-python mediapipe pillow pynput
```

## ▶️ How to Run

Launch the program with:
```commandline
python main.py
```


Make sure your webcam is connected and accessible.

The virtual keyboard window appears—type by pinching two fingers above the keys 👇👆.

Press **Esc** to exit the application safely 🔚.

---

## 💡 Notes & Tips

- Keyboard window is click-through for seamless multitasking 🖱️.
- Drag anywhere on the keyboard to reposition it 🖱️➔📍.
- Customize colors, key sizes, and delay intervals easily in the code 🎨🔧.
