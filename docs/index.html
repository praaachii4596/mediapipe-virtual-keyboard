🎹 Virtual Keyboard with Hand Tracking Demo

Welcome to the Virtual Keyboard project page! This project allows you to type using hand gestures tracked by your webcam.

🌟 Features

  • Real-time hand and finger tracking with Mediapipe.
  • Transparent, draggable virtual keyboard overlay.
  • Key press detection by pinching index and middle fingers.
  • Supports Shift (uppercase), Backspace, and Space keys.
  • Debounced inputs to prevent accidental repeats.

🎥 Demo Video

🚀 Run Locally

1. Clone the repo:

git clone https://github.com/praaachii4596/mediapipe-virtual-keyboard.git
cd YOUR_REPO

2. Install dependencies:

pip install opencv-python mediapipe pillow pynput

3. Run the script:

python main.py
